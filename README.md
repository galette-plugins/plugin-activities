# Galette Activities plugin

[![GitHub license](https://img.shields.io/github/license/galette-plugins/plugin-activities)](https://github.com/galette-plugins/plugin-activities/blob/main/COPYING)

### English

A [Galette](https://galette.eu) plugin to manage activities and subscriptions.

* website: https://galette-plugins.github.io/plugin-activities/
* bugs and features: https://github.com/galette-plugins/plugin-activities/issues
* mailing lists:
  * users: https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * developers: https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation: https://galette-plugins.github.io/plugin-activities/documentation.html

To use Galette Activities plugin, you'll need a reliable Galette version, and of course the plugin itself by either:

* download latest version available from the [releases page](https://github.com/galette-plugins/plugin-activities/releases)
* use [Galette Activities plugin source code from repository](https://github.com/galette-plugins/plugin-activities), this solution requires some technical skills
